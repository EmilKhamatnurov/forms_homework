# Forms Homework

## Создание приложения

Приложение было создано с помощью **`create-react-app`**.

## Архитектура проекта

Архитектура приложения основана на принципах методологии **FSD** (Feature-Sliced Design).

## Структура проекта

- Страницы приложения расположены в директории: **`src/pages`**.
- Компоненты **Signup** и **Signin** находятся по пути: **`src/features/auth/ui`**.

## Настройка UI

Для стилизации интерфейса был реализован кастомный компонент **`Input`**, который находится в директории:  
**`src/shared/ui/Input`**.
